# Getting Started
## Everyone
1. #### Review:

   a. The echoes mission statement and project overview on https://www.echoes-vip.org/	

   b. The RIT VIP overview - https://www.rit.edu/verticallyintegratedprojects/ 

   c. General references on Agile & Scrum
        -  https://agilemanifesto.org/ 
        -  [Learn about Agile and Scrum](https://www.mountaingoatsoftware.com/agile/new-to-agile-or-scrum) 
2. #### Review the course information in myCourses
3. #### Complete the semester when2meet - https://www.when2meet.com/?30430227-yTVvL 
4. #### Check out the [Projects](https://drive.google.com/drive/u/1/folders/1H5WF9GUf0kaibstQ_3ajsFBKM58-z2UL) folder and look into the documentation of the game you are assigned to.
5. #### Go to https://www.echoes-vip.org/about/team-organization to learn more about your role. 
6. #### Go to Technical Standards in the [GitHub Organization Docs](https://github.com/rit-vip-echoes), and read up on the technical practices related to echoes. 
7. #### Research!
    a. Read the Poems
   
    b. Play Games!
      - Play each previous game for echoes so far
        - [Myth of Change](https://rit-vip-echoes.github.io/Myth-of-Change/)
        - [Dream Swimmer](https://rit-vip-echoes.github.io/Dream-Swimmer/)
        - [Jelly Beach](https://rit-vip-echoes.github.io/Jelly-Beach/)
        - [Hush](https://rit-vip-echoes.github.io/Hush/)
      - Play the current echoes games in development!
        - [Smoke & Mirrors]()
        - [Reverb]()
        - [Room For Growth]()
      - https://www.jordanmagnuson.com/games is another good place to start, please share suggestions in Discord for similar games.
      - As you play, think about how each game makes you feel? What about the game is creating that feeling?
      - Consider this from a player perspective, but also from the perspective of your planned role for this project. How can you, via your planned responsibilities, contribute towards creating clear, concise, poetic experiences for players?


## Leads
1. Update your game’s github projects board to be consistent with the following [template](https://github.com/orgs/rit-vip-echoes/projects/3). This will help streamline task management across the teams.
2. Update and migrate your team's project documentation. 

   a. Move the technical documentation (code, architecture, systems) to the Wiki present on the games repository. This Wiki will utilize [markdown](https://www.markdownguide.org/basic-syntax/). It is possible to copy and paste as markdown from a google doc. 

   b. Update current project documentation to follow the new [template](https://docs.google.com/document/d/1SdMDYFMTH7wyNy-lV4VqURDsObRT_uHVAjb0iYJkCDc/edit?tab=t.0), which utilizes tabs to organize information.
