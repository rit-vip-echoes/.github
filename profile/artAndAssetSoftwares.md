# **Aesthetics: Art & Asset Softwares**

## 2D Animation
[Pencil2D](https://www.pencil2d.org/) – completely open source 
           
Pencil2D is a free 2D animation software with a simplistic user interface. Pencil2D’s minimalist architecture makes it perfect for finding what you need to change something’s properties. Pencil2D’s canvas gives a lot of freedom to the artist in the sense that it is practically infinite (while only rendering whatever is inside of the camera’s viewport). This can be used to change the resolution of a scene, but changing the camera’s viewport may offset the grid on the canvas. By sacrificing more tools for a more navigable interface, the user is required to do their own fine-tuning if they need to change some properties. I believe Pencil2D is a great software that is very user-friendly, but when making assets with set restrictions, it requires some tedious fine-tuning.

[OpenToonz](https://opentoonz.github.io/e/) – completely open source
            
OpenToonz is a free 2D animation software that has some very detailed and easy-to-use tools for artists. When using OpenToonz for the first time, the artist must first apply and rearrange all of the windows/tools. This makes the initial startup window look quite empty, but it’s to get the user to place everything they need wherever they want it, without making any assumptions on where it should be. This tutorial by NobleFrugal Studio is helpful in establishing the software’s terminology, getting the “rooms” (interface) set up, and explaining its tools. I definitely think that there are better free softwares for animation, as the animation window has some unusual icons, but it has some great functionality once you learn to use it.

## 3D Animation
[Maya](https://www.autodesk.com/products/maya/overview?term=1-YEAR&tab=subscription) – closed source/commercial use, industry standard
       
Maya is Autodesk’s closed source, industry standard 3D modeling software. This software is free to use with a student license, but requires payment for commercial use.

[Blender](https://www.blender.org/) – completely open source

[ZBrush](https://www.maxon.net/en/zbrush) – closed source/paid service
         
ZBrush is Maxon’s paid service 3D modeling software that is particularly useful when sculpting models. This software is used as an alternative to Blender or Maya for ease-of-use, allowing the artist to create more complex models with better tools to add more detail and speed up the process.

[Substance Painter](https://www.adobe.com/products/substance3d/apps/painter.html) – closed source/commercial use, industry standard
                    
Substance Painter is Adobe’s closed source, industry standard software to create textures for 3D models. Similar to Maya, this software is available for free with a student license, but it is a paid service when using it for commercial use.

## Image Editing
[Inkscape](https://inkscape.org/) – completely open source, vector-based
           
Inkscape is an amazing, free vector editing software that has many great and easy-to-use tools. Something that I really enjoyed about Inkscape was how many different functionalities it had so that I could get my desired design while also keeping my canvas organized. It may take a few hours with the software to get a grip of everything it has to offer, but it is a very useful software to learn about (here is a tutorial from Logos by Nick that should help with learning Inkscape).

[GIMP](https://www.gimp.org/) – completely open source, raster-based
       
GIMP is a free raster-based photo editing software that has some similar qualities to Photoshop.

## Asset Libraries
### Using Online Assets
Game asset libraries can be a very useful tool whenever work becomes overwhelming or when an asset is so common/small that it would be more convenient to use online assets, BUT do not let open source content take over the project. A game crowded with too much online art could become a distraction to the player, so take good care in keeping a cohesive style.

[OpenGameArt.Org](https://opengameart.org/) – completely open source, 2D Assets, 3D Assets
                  
Great resource when looking for game assets such as models, textures, and audio. The website’s UI is a bit strange to look at, but it is a trustworthy resource for open source content to use in a game. As for all game asset libraries, it can be a very useful tool whenever work becomes overwhelming or when an asset is so common/small that it would be more convenient to use online assets, BUT do not let open source content take over the project. A game crowded with too much online art could become a distraction to the player, so take good care in keeping a cohesive style.

[Unity Asset Store](https://assetstore.unity.com/) – 2D Assets, 3D Assets
                    
The Unity Asset Store is a good place to look for any type of game assets you may need, but not all of the content is available for free. Although you could sort through the store’s free assets, pay attention to the licensing types of each asset that you want to use (as you should be doing with all assets).

[Sketchfab](https://sketchfab.com/3d-models/popular) – 3D Assets
            
Sketchfab has a lot of quality 3D assets, with a lot of them being fully textured and/or rigged. It is also good for 2D art when you need an asset to be a specific angle, as you can rotate and position a 3D model within Sketchfab without downloading the model. When looking up models, make sure to change the license to “Free Standard” in order to find free and copyright free models that echoes can use.
